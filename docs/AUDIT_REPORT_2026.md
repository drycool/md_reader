## Детализация проблем

#### #1: Отсутствует зависимость markdown

- **Файл:** `requirements.txt` (корень проекта)
- **Описание:** Библиотека `markdown` требуется для работы Flask приложения, но не добавлена в корневой `requirements.txt`
- **Причина:** Зависимость указана только в `web_editor/requirements.txt`

#### #2: Несовместимость sessionStorage и Flask session

- **Файлы:**
  - `web_editor/templates/index.html` (строки 254-256) — клиентский JavaScript
  - `web_editor/app.py` (строки 73-74, 115-117) — серверная сторона
- **Описание:** Контент сохраняется в `sessionStorage` (браузер), но читается из `Flask session` (сервер) — разные механизмы, данные не передаются
- **Решение:** Либо использовать Flask session на клиенте, либо передавать контент через URL

#### #3: Ошибка в условии загрузки временного контента

- **Файл:** `web_editor/templates/editor.html` (строка 369)
- **Описание:** Условие `if (tempContent && !'{{ content }}')` всегда работает некорректно
- **Решение:** Изменить логику проверки на `if (tempContent && '{{ content }}' === '')`

#### #4: Отсутствует favicon.ico

- **Файлы:** Все шаблоны
- **Описание:** При каждом запросе возвращается 404 для `/favicon.ico`
- **Решение:** Добавить favicon или обработать запрос

#### #5: Внешние CDN зависимости

- **Файлы:** Все HTML шаблоны
- **Описание:** Используются внешние ресурсы:
  - Font Awesome 6.4.0
  - Marked.js 4.3.0
- **Решение:** Добавить локальные резервные копии

#### #6: Pytest не установлен

- **Описание:** Тесты в папке `tests/` невозможно запустить
- **Решение:** Добавить `pytest` в `requirements.txt`

#### #7: Упрощённый парсер markdown в EXE

- **Файл:** `web_editor/md_reader_exe.py` (строки 49-110)
- **Описание:** Функция `simple_markdown()` поддерживает ограниченное подмножество markdown:
  - Не поддерживаются таблицы
  - Упрощённая обработка списков
  - Ограниченная поддержка форматирования
- **Решение:** Использовать библиотеку `markdown` или расширить парсер

#### #8: Неправильная обработка путей в viewer.html

- **Файл:** `web_editor/templates/viewer.html` (строка 335)
- **Описание:** `const fp = filePath.replace(/\\\\/g, '/')` — двойная замена может не работать
- **Решение:** Использовать `filePath.replace(/\\/g, '/')`

#### #9: Две разные реализации сервера

- **Файлы:**
  - `web_editor/app.py` — Flask версия
  - `web_editor/md_reader_exe.py` — встроенный HTTP сервер
- **Описание:** Дублирование кода, могут расходиться со временем
- **Решение:** Унифицировать реализации

#### #10: run.bat работает только из корневой директории

- **Файл:** `run.bat`
- **Описание:** Относительный путь `py web_editor/app.py`
- **Решение:** Использовать абсолютный путь или добавить проверку

#### #11: Нет обработки ошибок в simple_markdown

- **Файл:** `web_editor/md_reader_exe.py`
- **Описание:** Функция не имеет try-except для некорректного markdown
- **Решение:** Добавить обработку исключений

#### #12: Несогласованность путей в bat файлах

- **Файлы:** `run.bat`, `view_demo.bat`, `edit_demo.bat`
- **Описание:** Разные пути к `demo.md`
- **Решение:** Унифицировать пути
