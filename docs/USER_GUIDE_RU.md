# Руководство пользователя MD Reader

## Введение

MD Reader - это мощный инструмент для работы с Markdown документами, который предоставляет как командную строку для просмотра, так и веб-интерфейс для редактирования файлов.

## Установка

### Требования

- Python 3.9 или выше
- pip (менеджер пакетов Python)

### Установка в режиме разработки

```bash
# Клонирование репозитория (если необходимо)
git clone <repository-url>
cd md_reader

# Установка в режиме разработки
pip install -e .

# Для разработки (включает инструменты тестирования)
pip install -e ".[dev]"
```

## Использование CLI

### Базовые команды

```bash
# Просмотр одного файла в интерактивном режиме
md-viewer open document.md

# Просмотр всех файлов в директории
md-viewer open /path/to/markdown/files

# Запуск TUI интерфейса
md-viewer tui /path/to/markdown/files
```

### Интерактивный режим

После запуска команды `md-viewer open` вы попадете в интерактивный режим:

1. Введите поисковый запрос для поиска по заголовкам
2. Выберите нужный результат из списка
3. Просмотрите содержимое секции
4. Повторите поиск или введите 'q' для выхода

### TUI режим

TUI режим предоставляет графический интерфейс в терминале:

```bash
md-viewer tui /path/to/markdown/files
```

## Использование веб-редактора

### Запуск веб-редактора

```bash
# Перейдите в директорию веб-редактора
cd web_editor

# Запустите редактор
python run.py
```

### Основные функции веб-редактора

1. **Редактирование** - редактируйте Markdown файлы в левой панели
2. **Предварительный просмотр** - просматривайте результат в правой панели
3. **Автосохранение** - файлы автоматически сохраняются каждые 30 секунд
4. **Навигация** - используйте оглавление для быстрого перехода к разделам
5. **Горячие клавиши**:
   - `Ctrl+S` - Сохранить файл
   - `Ctrl+O` - Открыть файл
   - `Ctrl+N` - Новый файл
   - `Ctrl+Shift+O` - Быстрое открытие файлов
   - `F11` - Полноэкранный режим

### Работа с файлами

- **Создание файла** - нажмите кнопку "Новый" или используйте Ctrl+N
- **Открытие файла** - выберите из списка или перетащите файл в редактор
- **Сохранение** - автоматическое или ручное (Ctrl+S)
- **Экспорт** - используйте кнопки экспорта для сохранения в HTML или TXT

## Компиляция в исполняемый файл

Для создания автономного исполняемого файла:

```bash
# Используйте PyInstaller
pip install pyinstaller

# Скомпилируйте main.py
pyinstaller --onefile web_editor/main.py
```

## Конфигурация

### Настройка логирования

```python
from md_reader.logger import setup_logging

# Логирование в файл
setup_logging(
    level="DEBUG",
    log_file="app.log",
    format_string="%(asctime)s | %(name)s | %(levelname)s | %(message)s"
)

# Логирование в консоль
setup_logging(level="INFO")
```

### Кастомизация валидации

```python
from md_reader.validators import FileContentValidator

# Изменение максимального размера файла (по умолчанию 10MB)
FileContentValidator.MAX_FILE_SIZE = 5 * 1024 * 1024  # 5MB
```

## Устранение неполадок

### Распространенные проблемы

1. **Ошибка импорта модулей**:
   - Убедитесь, что вы находитесь в корневой директории проекта
   - Проверьте, что виртуальное окружение активировано

2. **Проблемы с отображением веб-редактора**:
   - Проверьте, что все зависимости установлены
   - Убедитесь, что порт 5000 свободен

3. **Ошибки безопасности**:
   - Проверьте права доступа к файлам
   - Убедитесь, что путь к файлам не выходит за пределы разрешенной директории
