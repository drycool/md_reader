# Спецификация проекта MD Reader

## Обзор проекта

MD Reader - это расширяемый инструмент для работы с Markdown документацией, который включает в себя как CLI-интерфейс, так и веб-редактор. Проект создан для удобного просмотра, редактирования и управления коллекциями Markdown файлов.

## Архитектура системы

### Основные компоненты

1. **md_reader CLI** - Интерактивный инструмент командной строки для просмотра Markdown документации
2. **web_editor** - Веб-редактор Markdown файлов с графическим интерфейсом
3. **md_reader модули** - Библиотека переиспользуемых компонентов

### Структура проекта

```
md_reader/
├── md_reader/              # Основная библиотека
│   ├── cli.py             # CLI интерфейс
│   ├── loader.py          # Загрузка файлов
│   ├── toc.py             # Построение оглавления
│   ├── viewer.py          # Просмотр содержимого
│   ├── tui.py             # Текстовый интерфейс
│   ├── cache.py           # Кэширование
│   ├── container.py       # DI контейнер
│   ├── exceptions.py      # Исключения
│   ├── interfaces.py      # Интерфейсы
│   ├── logger.py          # Логирование
│   ├── validators.py      # Валидация
│   └── enhanced_loader.py # Расширенная загрузка
├── web_editor/            # Веб-редактор
│   ├── app.py            # Flask приложение
│   ├── run.py            # Скрипт запуска
│   ├── main.py           # Точка входа для EXE
│   ├── templates/        # HTML шаблоны
│   ├── static/           # Статические файлы
│   └── uploads/          # Загруженные файлы
├── tests/                 # Тесты
├── docs/                  # Документация
└── dist/                  # Скомпилированные файлы
```

## Функциональные возможности

### CLI Режим (md_reader)

- Чтение отдельных файлов или целых директорий с Markdown файлами
- Автоматическое построение оглавления по заголовкам
- Интерактивный поиск по заголовкам с нечетким соответствием
- Просмотр секций с подсветкой синтаксиса
- Кэширование оглавления для улучшения производительности
- Безопасная обработка путей и файлов
- Централизованное логирование

### Веб-редактор

- Современный графический интерфейс с градиентным дизайном
- Живой предварительный просмотр в реальном времени
- Подсветка синтаксиса кода
- Автоматическое оглавление с навигацией
- Автосохранение каждые 30 секунд
- Горячие клавиши для быстрой работы
- Поддержка drag-and-drop для файлов
- Полностью локализованный русский интерфейс
- Адаптивный дизайн для разных устройств

## Технический стек

### Зависимости

- **Python 3.9+**
- **Flask** - веб-фреймворк
- **rich** - форматирование вывода в терминале
- **typer** - CLI интерфейс
- **markdown-it-py** - парсинг Markdown
- **python-Levenshtein** - нечеткий поиск
- **textual** - TUI интерфейс
- **Jinja2** - шаблонизация
- **MarkupSafe** - безопасная обработка HTML

## Безопасность

- Защита от path traversal атак
- Валидация размера файлов
- Проверка кодировки файлов
- Санитизация пользовательского ввода
- Централизованная обработка ошибок

## Производительность

- Ленивая загрузка файлов
- Многоуровневое кэширование
- Параллельная обработка файлов
- Оптимизация использования памяти

## Расширяемость

- Интерфейс-ориентированная архитектура
