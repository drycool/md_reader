# Claude Code Guide Agent

## Описание

Встроенный агент для ответов на вопросы о Claude Code. Доступен через `subagent_type: "claude-code-guide"`.

## Использование

```
Agent tool с subagent_type: "claude-code-guide"
```

## Вопросы, которые покрывает

- Как использовать Claude Code
- Как настроить хуки (hooks)
- Как создать пользовательские команды
- Как работать с MCP серверами
- Как настроить горячие клавиши
- Как использовать Agent SDK
- Как работать с Anthropic API

## Примеры вопросов

- "Как создать команду?"
- "Как настроить pre-command хук?"
- "Что такое MCP серверы?"
