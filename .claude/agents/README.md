# Claude Code Agents

## Доступные агенты

| Агент | Описание |
|-------|----------|
| `explore.md` | Исследование кодовой базы, поиск файлов и кода |
| `plan.md` | Планирование реализации, архитектурные решения |
| `general-purpose.md` | Универсальный агент для сложных задач |

## Использование агентов

Агенты вызываются через Agent tool с параметром `subagent_type`:

```
Agent tool с subagent_type: "Explore"
Agent tool с subagent_type: "Plan"
Agent tool с subagent_type: "general-purpose"
```

## Создание новых агентов

Создайте markdown файл в `.claude/agents/` с описанием:

```markdown
# Agent name

## Описание

Что делает этот агент.

## Возможности

- возможность 1
- возможность 2

## Использование

Когда использовать этого агента.

## Примеры

- "пример задачи 1"
- "пример задачи 2"
```
