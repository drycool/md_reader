# Claude Code Hooks

## Доступные хуки

| Хук | Описание |
|-----|----------|
| `pre-command.bash` | Выполняется перед каждой командой |
| `on-write-write.sh` | Выполняется после записи файла |

## Структура хука

```bash
#!/bin/bash
# $1 = tool name
# $2 = JSON с параметрами инструмента

echo "Tool called: $1"
```
