# Claude Code Commands

## Доступные команды

| Команда | Описание |
|---------|----------|
| `/view` | Открыть demo.md в просмотрщике |
| `/edit` | Открыть demo.md в редакторе |
| `/test` | Запустить unit тесты |

## Использование

Команды вызываются через `/command_name` в чате с Claude Code.

## Создание новых команд

1. Создайте файл `.claude/commands/<имя>.md`
2. Добавьте описание в формате:
   ```markdown
   # Имя команды

   Описание команды.

   ## Использование

   ```
   /имя
   ```

   ## Описание

   Подробное описание...
   ```
