#### 3. Исправленные баги

##### Баг 1: Путь к файлу не передаётся при encodeURIComponent
**Проблема:** Windows-пути с обратными слешами (`D:\path\file.md`) терялись при передаче через URL.
**Симптом:** Пустой экран редактора при переходе из view в edit.
**Решение:** В JavaScript заменяем `\` на `/` перед encodeURIComponent.

Исправлено в:
- `templates/viewer.html` (кнопка "Редактировать")
- `templates/editor.html` (кнопка "Просмотр")

##### Баг 2: Относительные пути файлов
**Проблема:** Bat-файлы передавали относительные пути (`markdown_files/demo.md`), сервер искал от `web_editor/`, не находил.
**Решение:** Добавлена функция `resolve_file_path()` в `app.py`, которая ищет файл относительно корня проекта.

##### Баг 3: URL кодирование при запуске
**Проблема:** Python формировал URL без `quote()`, слеши не кодировались.
**Решение:** Добавлен `from urllib.parse import quote` и `quote(file_path, safe='')` в `app.py`.

#### 4. Известные проблемы (требуют исправления)

##### Проблема A: Пустой контент при переходе view → edit
**Симптом:** При переходе из просмотра в редактор — пустой экран.
**Причина:** Не передаётся content при рендеринге editor.html.
**Статус:** ТРЕБУЕТ ИСПРАВЛЕНИЯ

##### Проблема B: Нельзя сохранить файл
**Симптом:** Кнопка "Сохранить" — ошибка "путь к файлу не указан".
**Причина:** `filePath` не передаётся в JavaScript функции сохранения.
**Статус:** ТРЕБУЕТ ИСПРАВЛЕНИЯ

##### Проблема C: Ложное сообщение о несохранённых изменениях
**Симптом:** При нажатии "Просмотр" в редакторе — сообщение "Есть несохранённые изменения", хотя изменений нет.
**Причина:** Сравнение строк `editor.value !== originalContent` некорректно работает с Jinja2 шаблоном.
**Статус:** ТРЕБУЕТ ИСПРАВЛЕНИЯ

##### Проблема D: CDN зависимость
**Симптом:** Могут не загружаться шрифты (FontAwesome) и скрипты (marked.js).
**Решение:** Рекомендуется добавить локальные резервные копии.
**Статус:** НИЗКИЙ ПРИОРИТЕТ
