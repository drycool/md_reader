# 🚀 Веб-редактор Markdown

Красочный и современный веб-редактор для работы с Markdown документами, созданный на основе проекта `md_reader`. Полностью русифицированный интерфейс со всеми служебными уведомлениями на русском языке.

## ✨ Основные возможности

- 🎨 **Красивый интерфейс** с современным градиентным дизайном
- 👀 **Живой предварительный просмотр** - результат отображается в реальном времени
- 🌈 **Подсветка синтаксиса** для комфортного редактирования
- 📋 **Автоматическое оглавление** с быстрой навигацией по заголовкам
- 💾 **Автосохранение** каждые 30 секунд
- ⌨️ **Горячие клавиши** для быстрой работы
- 🔍 **Быстрый поиск** файлов (Ctrl+Shift+O)
- 📱 **Адаптивный дизайн** для работы на любых устройствах
- 🇷🇺 **Полная русификация** всех элементов интерфейса
- 🛠️ **Расширенная панель инструментов** с визуальными кнопками
- 📊 **Статистика документа** (слова, символы, время чтения)
- 🎯 **Контекстное меню** с дополнительными функциями

## 🛠️ Установка и запуск

### Предварительные требования

- Python 3.9 или выше
- Виртуальное окружение md_reader (или совместимое)

### Быстрый старт

1. **Убедитесь, что вы находитесь в виртуальном окружении:**
   ```bash
   cd C:\Users\369\.qoder\md_reader
   md_reader_working\Scripts\activate
   ```

2. **Установите дополнительные зависимости:**
   ```bash
   pip install flask watchdog python-dotenv
   ```

3. **Перейдите в папку веб-редактора:**
   ```bash
   cd web_editor
   ```

4. **Запустите редактор:**
   ```bash
   python run.py
   ```

5. **Откройте браузер по адресу:** http://localhost:5000

### Расширенные опции запуска

```bash
# Запуск на другом порту
python run.py --port 8080

# Запуск с доступом из сети
python run.py --host 0.0.0.0 --port 5000

# Запуск в режиме отладки
python run.py --debug

# Запуск без автоматического открытия браузера
python run.py --no-browser
```

## 🎯 Основные функции

### Режимы работы

1. **📝 Редактор** - режим только редактирования с подсветкой синтаксиса
2. **👁️ Предварительный просмотр** - режим только просмотра результата
3. **⚡ Разделённый режим** - редактор и просмотр одновременно

### Панель инструментов

- **Жирный** (`**текст**`) - выделение жирным шрифтом
- **Курсив** (`*текст*`) - выделение курсивом  
- **Зачёркнутый** (`~~текст~~`) - зачёркивание текста
- **Заголовок** (`# Заголовок`) - создание заголовков
- **Ссылка** (`[текст](URL)`) - вставка ссылок
- **Изображение** (`![alt](URL)`) - вставка изображений
- **Код** (`` `код` ``) - выделение кода
- **Цитата** (`> текст`) - создание цитат
- **Список** (`- элемент`) - создание списков
- **Таблица** - вставка готовой таблицы
- **Горизонтальная линия** (`---`) - разделительная линия

### Горячие клавиши

| Комбинация | Действие |
|------------|----------|
| `Ctrl+S` | Сохранить файл |
| `Ctrl+O` | Открыть файл |
| `Ctrl+N` | Создать новый файл |
| `Ctrl+Shift+O` | Быстрое открытие файлов |
| `F11` | Полноэкранный режим |
| `Esc` | Выход из полноэкранного режима |
| `F1` | Справка |

### Управление файлами

- **Создание** - кнопка "Новый" или Ctrl+N
- **Открытие** - кнопка "Открыть", выбор из списка или перетаскивание
- **Сохранение** - автоматическое или ручное (Ctrl+S)
- **Скачивание** - кнопка "Скачать" для загрузки на компьютер

## 🔧 Технический стек

### Backend
- **Flask 2.3+** - веб-фреймворк
- **markdown-it-py** - парсинг Markdown
- **python-Levenshtein** - нечёткий поиск
- **rich** - форматирование вывода
- **модули md_reader** - переиспользование существующей логики

### Frontend  
- **HTML5** - разметка
- **CSS3** с градиентами и анимациями - стилизация
- **JavaScript ES6** - интерактивность
- **CodeMirror** - редактор кода с подсветкой синтаксиса
- **Marked.js** - рендеринг Markdown в HTML
- **Highlight.js** - подсветка синтаксиса в блоках кода
- **Font Awesome** - иконки

## 🎨 Дизайн и UI/UX

### Цветовая схема
- **Основной градиент:** синий → фиолетовый (`#667eea` → `#764ba2`)
- **Акцентные цвета:** различные оттенки для кнопок и элементов
- **Прозрачность:** использование `backdrop-filter: blur()` для современного вида

### Адаптивность
- **Десктоп:** полный интерфейс с боковой панелью
- **Планшет:** сжатый интерфейс с возможностью скрытия панелей
- **Мобильные:** оптимизированный интерфейс с выдвижной боковой панелью

## 🔌 API документация

Редактор предоставляет REST API для интеграции с другими системами:

### Основные эндпоинты

- `GET /api/files` - список файлов
- `GET /api/file/<filename>` - содержимое файла
- `POST /api/file/<filename>` - сохранение файла
- `POST /api/upload` - загрузка нового файла
- `POST /api/new` - создание нового файла
- `GET /api/download/<filename>` - скачивание файла

Подробная документация доступна в файле `api_документация.md` после запуска редактора.

### Интеграция с md_reader

Веб-редактор полностью использует модули проекта md_reader:

- `md_reader.loader` - загрузка и кеширование файлов
- `md_reader.toc` - построение оглавления  
- `md_reader.enhanced_loader` - расширенная загрузка
- `md_reader.validators` - валидация данных

### Частые проблемы

**Ошибка импорта модулей md_reader:**
```bash

cd C:\Users\369\.qoder\md_reader
```

```bash

```

- Убедитесь что достаточно места на диске
